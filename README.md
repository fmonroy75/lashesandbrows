# Lashes & Brows Montréal

Premium bilingual (English / Spanish) Nuxt website for lashesandbrows.ca.

## Run

```bash
npm install
npm run dev
```

Then open the local URL shown by Nuxt.

## Build

```bash
npm run generate
```

The generated static site will be in `.output/public`.

## Images

The real client images are in:

`public/images/`

Replace them with the original-resolution photos when available. The current files are the uploaded versions.
